# Exploratory scripts (archive)

These are the screening scripts from the volume-clock exploration, kept for
audit. They were run from the family directory before being moved here.

They are **not** part of the frozen strategy. To rerun one, either copy it to
`research/new/family-volume-clock/` or change its `HERE`/`ROOT` paths so that
`strategy.py` and `research/bt.py` are importable.

The frozen implementation and the report are one level up:

- `../strategy.py`
- `../result.json`
- `../robustness.py`
- `../report.md`
- `../HYPOTHESIS.md`

All exploration used the development window 2016-01-04 .. 2023-12-29 only.
